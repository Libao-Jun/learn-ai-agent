## Agent 架构介绍

### Agent（智能体）
在 AI 应用开发中，`Agent（智能体）`是指能够感知环境、自主做出决策、并采取行动的 AI 系统。

### Agent 架构
`Agent 架构`是指 Agent 系统中各个组件的组织方式，决定了 Agent 的能力边界、可靠性、灵活性和适用场景。


### Agent 的工作方式本质
Agent 的工作方式本质上是一个`循环（Loop）`——感知当前状态，推理下一步，执行行动，再次感知……直到任务完成。

```mermaid
graph LR
    A[感知环境] --> B[推理决策]
    B --> C[执行行动]
    C -->|观察结果，继续循环| A
```

## 常用架构

### 架构一：单 Agent 循环

```mermaid
graph TB
    A[用户任务输入] --> B[感知 - 收集上下文<br>读取文件、获取状态]
    B --> C[Agent输入]
    C --> D[推理 - 决定下一步<br>分析情况，选择工具]
    D --> F[行动 - 调用工具<br>Bash / Read / Edit...]
    F -.->|继续循环| B
```
