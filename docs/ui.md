# UI 风格升级 —— 面向 AI 时代的科技感改造

> **角色**：你是一位资深 UI/UX 工程师，擅长现代科技风格（cyberpunk / glassmorphism / neon-tech）的前端实现。
> **目标**：在不改动任何业务逻辑的前提下，对现有项目进行纯视觉层面的科技感升级。
> **优先级**：P0（高优先级，影响全局品牌感知）

---

## 1. 色彩系统

将全局 CSS 变量替换为以下色板。**所有颜色必须通过 CSS 自定义属性（design tokens）引用，禁止硬编码色值。**

### 1.1 暗色主题（默认）

| 令牌                       | 色值                      | 用途                   |
| -------------------------- | ------------------------- | ---------------------- |
| `--color-bg`               | `#0a0a0f`                 | 页面主背景             |
| `--color-bg-alt`           | `#111827`                 | 次级背景（卡片、面板） |
| `--color-surface`          | `rgb(255 255 255 / 0.04)` | 半透明表面（毛玻璃）   |
| `--color-text`             | `#e2e8f0`                 | 正文（蓝调白，非纯白） |
| `--color-text-muted`       | `#94a3b8`                 | 辅助文字               |
| `--color-text-dim`         | `#64748b`                 | 三级文字（最淡）       |
| `--color-accent`           | `#00d4ff`                 | 主强调色（科技蓝）     |
| `--color-accent-secondary` | `#a78bfa`                 | 辅助强调色（淡紫）     |
| `--color-accent-glow`      | `#22d3ee`                 | 发光态（青）           |

### 1.2 约束

- **禁止使用** `#000`（纯黑）、`#fff`（纯白）、高饱和度红/黄/绿（`#ff0000`、`#ffff00`、`#00ff00`），除非用于状态警示色
- 所有渐变采用 `蓝(#00d4ff) → 紫(#a78bfa)` 方向，不引入第三种色相

## 2. 材质与氛围

### 2.1 毛玻璃效果

适用于：导航栏、侧边栏、卡片（悬停态）、弹出层。

```css
backdrop-filter: blur(12px) saturate(160%);
background: rgb(255 255 255 / 0.03);
border: 1px solid rgb(255 255 255 / 0.06);
```

### 2.2 发光边缘

适用于：主按钮（`.btn-primary`）、特色卡片（`.featured-card`）、当前激活项。

```css
/* 默认 */
box-shadow: 0 0 12px rgb(0 212 255 / 0.15);
/* 悬停 */
box-shadow:
  0 0 24px rgb(0 212 255 / 0.3),
  0 0 48px rgb(167 139 250 / 0.12);
```

### 2.3 渐变使用原则

- **仅在以下场景使用渐变**：标题文字、关键 CTA 按钮、分割线、进度条
- **禁止**在正文段落、大背景区域使用渐变
- 渐变方向统一为 `135deg`（左上→右下），`background-size: 200%` + 位移动画

## 3. 动效与交互

### 3.1 悬浮反馈（Hover）

| 元素 | 效果                               | 时长  |
| ---- | ---------------------------------- | ----- |
| 按钮 | `translateY(-2px)` + 阴影加深      | 0.2s  |
| 卡片 | `translateY(-3px)` + 边框变 accent | 0.3s  |
| 链接 | 颜色渐变到 accent + 下划线滑入     | 0.25s |
| 图标 | 微缩放 `scale(1.08)` + 发光        | 0.2s  |

### 3.2 加载态

- **骨架屏**：使用 `shimmer` 动画（`background-position` 从 `-200%` 扫到 `200%`）
- **呼吸光晕**：使用 `pulseGlow` 关键帧（`box-shadow` 在 `0.15` 和 `0.3` 透明度之间循环，周期 2s）

### 3.3 过渡规范

所有交互属性变化必须包含 `transition`，统一缓动函数：

```css
--ease-out: cubic-bezier(0.16, 1, 0.3, 1); /* 用于位移/缩放 */
--ease-smooth: cubic-bezier(0.4, 0, 0.2, 1); /* 用于颜色/透明度 */
```

## 4. 氛围装饰（按需启用）

以下为 **可选增强项**，实施后需由人工确认是否保留。每项独立开关（通过 CSS 类名或注释即可）。

### 4.1 背景网格线

纯 CSS 实现，不引入额外 DOM 元素：

- `background-image: linear-gradient(...)` 绘制 1px 网格
- `mask-image: radial-gradient(...)` 边缘淡化
- 整体 `opacity: 0.15`，不遮挡内容

### 4.2 环境光晕

- 2~3 个固定定位的圆形径向渐变（`filter: blur(120px)`）
- 颜色：蓝（`#00d4ff`）/ 紫（`#a78bfa`），透明度 ≤ 0.08
- 带缓慢浮动动画（`translateY` ±8px，周期 8s）

### 4.3 装饰光条

- 页面顶部固定 2px 高渐变线（蓝→紫→透明）
- 或 hero 区域侧边一条垂直发光细线
- 使用 `::before` / `::after` 伪元素，不增加 DOM 节点

## 5. 改造范围与优先级

| 优先级 | 模块                                 | 预计影响文件                     |
| ------ | ------------------------------------ | -------------------------------- |
| **P0** | 全局 CSS 变量（design tokens）       | `global.css` 或 `colors.css`     |

| **P1** | 主题配置统一                         | tailwind.config / CSS 变量文件   |
| **P2** | 氛围装饰（网格线 / 光晕 / 光条）     | 全局 CSS + 布局组件              |

## 6. 约束条件

1. **不修改任何业务逻辑** — 仅限 CSS 和视觉层标记（HTML class/结构微调）
2. **不修改构建配置文件** — `astro.config`、`package.json`、`tsconfig`、`tailwind.config`（除非仅追加颜色令牌）
3. **响应式保持** — 所有改动需在 375px / 768px / 1200px 三个断点测试通过
4. **不引入新依赖** — 所有效果用纯 CSS 实现，不使用 Framer Motion 等第三方动效库
5. **注释清晰** — 每个新增 CSS 块前标注 `/* ── Section Name ── */` 分隔注释
